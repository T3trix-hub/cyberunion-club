# 🎮 Кибер Юнион — сайт компьютерного клуба

Многостраничный сайт компьютерного клуба «Кибер Юнион» (ТЦ «Титан», Минск): залы и цены, библиотека игр, контакты. Тёмный киберпанк-дизайн, адаптив, анимации. Чистые HTML, CSS и JS без сборки.

**Страницы:** `index.html` (главная), `halls.html` (залы и таблица цен), `games.html` (игры с фильтром по жанрам), `contacts.html` (контакты и карта).

## Что менять
Всё в `js/data.js`: `SITE` (адрес, телефон, Telegram, Instagram), `HALLS` (залы и цены), `GAMES` (список игр).

## Обложки игр
Необязательно. Положи картинку в `images/games/` и назови по id игры (`cs2.jpg`). Без картинки плитка рисуется сама. Используй только материалы, на которые у клуба есть права.

## Публикация на GitHub Pages
Залей содержимое папки в корень репозитория (не `.zip`), затем **Settings → Pages → Deploy from a branch → `main` / `(root)`**.

Сайт сделал [T3trix](https://t3trix-hub.github.io/t3trix-portfolio/). Логотип, фото и названия принадлежат клубу.
